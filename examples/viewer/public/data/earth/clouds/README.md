# Earth cloud map

`blue-marble-clouds-8k.jpg` is NASA's Blue Marble cloud composite, 8192 × 4096,
equirectangular, north-up, longitude −180° at the left. It is one fixed set of clouds
from 2001, not current weather. Brightness is cloud cover.

- Credit: NASA Goddard Space Flight Center, image by Reto Stöckli.
- Original: `cloud_combined_8192.tif`, Visible Earth image 57747. NASA's server no
  longer answers, so it came from the Internet Archive:
  https://web.archive.org/web/20261018141030/https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57747/cloud_combined_8192.tif
